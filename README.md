## Día 13 de Noviembre 2026: Fundamentos de la web 

### Internet no es lo mismo que la web

### Internet
Es la red física mundial de computadoras conectadas entre sí, formada por cables, fibra óptica, antenas y routers. Esta infraestructura permite la interconexión de millones de dispositivos a nivel global, creando una auténtica "carretera" por donde viaja la información. Cada computadora conectada a Internet es conocida como un nodo, y estos nodos se comunican entre sí a través de protocolos de red como TCP/IP.

### World Wide Web "www" (la web)
Es un servicio que funciona sobre Internet: el conjunto de páginas web y aplicaciones que abrimos en un navegador. Es uno de los "vehículos" que usan la carretera de Internet. Por ejemplo, cuando accedemos a un sitio web como Wikipedia, estamos utilizando el World Wide Web. Este servicio utiliza protocolos como HTTP para transmitir información en formato HTML, permitiendo la visualización de contenido en páginas web.

### La diferencia entre las dos, fácil de entender es la siguiente
Internet es la infraestructura física y lógica que permite la comunicación entre dispositivos, mientras que la web es un conjunto de servicios y aplicaciones que utilizan esta infraestructura para proporcionar contenido y funcionalidades a los usuarios. Por ejemplo, si piensas en Internet como la carretera, la web sería como el coche que circula por ella. Sin Internet, no habría carretera, y sin la web, no habría vehículos que puedan recorrerla.

## Hosting 
El servicio que alquila espacio en un servidor para guardar los archivos del sitio

~~ El servicio que alquila espacio en un servidor para guardar los archivos del sitio web, comúnmente conocido como alojamiento web, es fundamental para la existencia de cualquier página en Internet. Este servicio permite a los propietarios de sitios web almacenar y gestionar todos los archivos necesarios para que su sitio funcione correctamente.

## Servidor 
La computadora física o virtual que almacena los archivos y responde a las solicitudes es la casa en sí

Un ejemplo de servidores en la nube puede ser Amazon Web Services (AWS).
Otro ejemplo es un servidor Linux con Apache 


## Las tres capas de una página web 
### HTML 
**Lenguaje de Marcado para Estructura y Contenido**

### CSS 
**Lenguaje de estilos que define la apariencia: colores, tipografías, tamaños y distribución**

### JavaScript 
**Lenguaje de **programación** que agrega **comportamiento**: responde a clics, valida formularios, carga datos.**
